# 에이전트 프롬프트

Obsidian Copilot 의 커스텀 프롬프트 폴더가 이 폴더로 설정돼 있습니다. 채팅 창에서 `/` 를 눌러 선택하거나, 다른 LLM 에 그대로 붙여 넣어 사용하세요. `{activeNote}` 는 Copilot 이 현재 노트로 치환합니다.

- [[01-Biblical-Researcher]] — 성경 본문 구조, 문맥, 역사적 배경을 연구한다.
- [[02-Original-Language-Analyst]] — 히브리어·헬라어의 문법, 의미, 용례를 분석한다.
- [[03-Commentary-Researcher]] — Vault 의 주석·사전을 모아 비교한다.
- [[04-Theology-Reviewer]] — 조직신학·성경신학 관점에서 해석을 검토한다.
- [[05-Source-Verification]] — 모든 주장을 원본 Markdown 과 대조한다.
- [[06-Sermon-Architect]] — 설교의 구조와 논지를 설계한다.
- [[07-Sermon-Writer]] — 승인된 개요로 한국어 설교 초안을 쓴다.
- [[08-Critical-Reviewer]] — 초안의 해석·논리·표현 오류를 검토한다.
- [[09-Final-Editor]] — 설교자의 문체를 유지하며 최종 퇴고한다.
